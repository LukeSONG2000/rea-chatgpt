# Chat／Work本轮实现与缺口（2026-11-13）

本轮主要补齐Android普通AppShell内的Chat／Work闭环；iOS沿用已运行版本，仅补充293静态证据。所有事件来自独立确定性合成适配器，不接真实服务，不调用本地模型或工具。

## 已实现

- Android正常主程序接入会话历史、新建、标题搜索、选择、重命名和非运行会话归档。
- 普通发送、增量、全文修订、完成、失败、停止与重试；按账户、资料、会话、消息、请求、attempt及订阅隔离。Delta要求连续，缺段转Interrupted保留正文，完整快照按修订规则恢复。
- Chat／Work分别保留选择和草稿；提交、清草稿及消息落盘原子更新。进程恢复时未完成请求转Interrupted，可主动重试。IME候选不持久化。
- 复用已有标准正文、代码和表格组件，按角色及请求隔离表格身份；阅读锚点和跟随状态恢复。
- 移除无293依据的顶部加号、侧栏居中新建按钮，新建接入既有侧栏底部聊天入口；清除本地选择是独立宿主策略。
