# 插件整项第六轮：目录、详情与设置贯通

本批只做iOS插件前端，官方基线1.2026.293。原制品摘要、偏移和局限见 `ios-plugins-detail-sixth-20261113-findings.json`、`ios-plugins-settings-sixth-20261113-findings.json`。不恢复后端、安装、外部授权或工具执行。

## 已实现

- 保留目录／来源／已安装／分页／搜索／描述展开／加载空失败重试／刷新保留旧结果和返回恢复。
- 详情补技能区：空数组隐藏，流式胶囊，默认前8项，剩余数量入口，展开后全量；不添加原证据没有的收起。中文标签及数量格式来自原资源。胶囊间距、paint、展开绑定和技能点击的说明页为独立宿主适配，最终原ScreenAction尚未恢复。
- 信息区在技能区之后：空数组隐藏，供给行按稳定ID和原顺序呈现，最后一行没有分隔线；支持文本、格式化字符串列表、URL。链接显示host或完整地址，复用已有离线浏览器打开／关闭。不是六项元数据常驻，也不把Skill当Tool。
- 设置→插件现在是独立分组Form。已添加列表与侧栏目录共用账户／工作空间的状态owner；浏览目录独立呈现，关闭回到设置，恢复此前目录路由。原nativePluginSettingsEnabled／hasInstalledPlugins／目录callback分支分别保留输入，不以目录callback存在证明开关已启用。此预览显式启用native分支，实际服务投影未知。
- 已添加行进入插件设置能力说明，明确原配置表单尚未接入；不误跳目录或详情。目录/技能/信息等个人内容全部为显式合成数据，不填入真实开发者版本或用户信息。
- 合成连接／断开状态保存到独立预览资料：只存version、账户、工作空间、插件展示/动作ID、修订、连接状态。写入成功后才发布成功；失败保持旧状态和重试，坏文件／错作用域不静默覆盖。冷启动重建元数据而不保存本地化文本、凭据、插件代码或授权。
- 普通预览用统一core配置；测试使用独立UUID。中英文资源与系统语言选择继续复用，不改用户主题或预览资料。
