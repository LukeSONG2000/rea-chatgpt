# Remote审批与补充输入：双端核心收口

本批只推进前端与异步服务接口，以两端各自1.2026.293制品为依据。确定性合成适配器不执行命令、模型、网络或真实审批。

## iOS实现

保留已有普通审批卡与同步接受owner，本次补充输入改为异步provider。一个请求只允许一个pending attempt，独立UUID、完整请求载荷和scope共同核对；请求更新或离页取消任务，旧完成不能清理新attempt或接受已替换的问题。

最后一题先暂存，异步接受成功才发布结束状态；失败保留输入，允许主动重试。中间题仍在本地推进。secret和答案仅在内存，已有checkpoint只保存接受身份，重启不重新种入已接受的问题。

293静态证据确认单独的userInputSubmissionTask、UUID及匹配后清理；原footer在dispatch前修改文本／答案。故本地暂存、失败保留、禁用控件、spinner和错误弹窗明确是独立宿主适配，不是已恢复的原始失败回滚或原版光学。原错误subject的消费者尚未闭合。

纯合同通过。中文浅色定向流程55.706秒通过，覆盖普通答案、保密字段、提交期间禁用、首次失败、重试接受及真正进程重启。首轮36.622秒停在ProgressView的独立AX查询：录像有spinner，但原生Button未另暴露子节点；只修正测试为检查父按钮禁用，产品未改。没有重复四格矩阵或既有普通审批整页测试。

模拟器及iphoneos构建、严格签名检查通过。已恢复原资料选择及四项语言／外观偏好，无参数启动保留预览，安装二进制摘要匹配。Air最新查询仍paired但tunnel unavailable／DDI false，本批没有装机。

机器入口：`ios-remote-request-async-ninth-parent-current-20261113.json`。两张错误／接受重启截图已查看；错误截图仍含弹窗关闭动画，不据此宣称无遮挡输入框几何正确。

## Android实现

Tool整题表单与Async分页追问分别接入，保留原源码的选择默认值、跳过／下一题、非空提交和全部为空的不同规则，不统一成iOS表单。通过正常任务列表进入两种合成任务。

请求替换、revision、过期、异步attempt和迟到回执分别核对；错误可重试，保存拒绝不先显示已接受。普通审批沿同一attempt门控，反馈移除rememberSaveable；答案和secret不落盘，仅接受身份记录持久化。

首次产品构建22秒通过，之后产品APK未变。纯合同、r3 Tool选择／保密字段提交片段及r4剩余Async／普通审批16.988秒、真正进程重启31.264秒共同覆盖核心。早期测试fake链式返回逃逸、无IME时错误Back、Next在视口下方的失败现场保留；只修正测试生命周期与定位，未以反复改产品迎合测试。未声称最终完整单方法旅程整体重跑通过。

最终测试源码定位同步编译通过；OnePlus安装APK与本地摘要一致，普通两个preview偏好摘要未变，正常AppShell保留前台。机器入口：`android-remote-user-input-parent-current-20261113.json`。
