# 登录／账户前端：Android 已完成部分（2026-11-13）

本次保存 Android 原生欢迎入口与独立离线账户闭环，不包含正在集成的 iOS 头像菜单。原 Android293 的实际认证采用 Auth Tab／Custom Tabs；当前本地演示不是官方授权网页，也不提供真实账号能力。

## 已实现

- 设置账户入口、欢迎、明确标示的本地认证演示、取消、失败重试、接受登录及退出后欢迎页。
- 本地会话先成功落盘再更新界面；异常记录保留，失败不会假装登录或退出成功。
- 账户、会话、请求和订阅代次隔离；旧请求与已销毁页面不能晚写数据。同一合成账户重登恢复其草稿，旧普通预览保留。
- 旧 Remote 直接入口也经过会话检查，不能绕过已退出状态。
