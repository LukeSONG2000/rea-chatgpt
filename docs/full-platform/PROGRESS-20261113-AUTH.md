# 第10项：登录／账户前端第四轮

## 已实现

- 欢迎页的 Apple／Google／原生入口、忙态、错误／重试／取消；外部认证服务入口保留。
- 原生邮箱 → 密码 → 验证码 → 前端会话；普通服务不返回伪造认证成功。当前验收配置显式使用合成服务，页面标注回放。
- 本批恢复293 AuthInputFieldStyle的实际父容器：内容上下10、外层左右12、HStack间距10、圆角16、最小高度框架、焦点／已有输入时的浮动标签与底部对齐。
- 密码按钮使用原 eye／eye-slash 图标与显示／隐藏密码原标签，共用原草稿 Binding；往返显示、隐藏保持输入，返回上一阶段清除秘密内容。
- 用户关闭旧错误窗口时，按原失败请求ID匹配，不再仅凭同一错误文案和流程代次清除新错误。
- 保留已恢复的资料编辑入口、Name／Username、保存失败／重试、取消、会话内父级更新。源状态及编辑器文件摘要与前轮一致，复用其操作证据。
- 退出确认、取消、忙态、匹配回执、根页面退休、欢迎页与聊天草稿返回构成一个整体前端闭环。
- 共享 `core-preview.json` 加入显式 `--auth-journey-fixture`。当前预览从聊天进入，不强制退出；可手动在设置退出后体验上述合成旅程。

## 未实现

- 真实认证、Apple／Google授权、账户后端、凭据存储或刷新。当前不以这些为前端验收条件。
- 手机号／国家与域名建议、找回／重发、Passkey／MFA／工作区、新账户完整资料与多账户宿主。
- 欢迎按钮选定分支的真实样式生产者仍在 ViewParams raw0 的 payload+0x70；56／28继续明确标为夹具值，未拿邻支38／20／16冒充几何。
- 输入框原始最小高度默认、供给字体颜色、完整 fieldCheck／信息行、点击回调赋值及弹簧参数未闭。当前54、语义字体／颜色、公共默认弹簧与未聚焦时聚焦回调属于宿主适配。
- 完整头像／图片编辑与上传、原表单验证、保存后自动关闭、完整呈现转场和认证专用触觉。
