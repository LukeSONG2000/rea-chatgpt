# Remote列表：iOS恢复与Android对齐

本批只处理列表整项，保留此前消息、设置和插件成果；没有业务服务端或真实Remote执行。移动官方基线分别为1.2026.293，Android不以iOS代码证明原始结构。机器记录：`ios-remote-list-checkpoint-parent-current-20261113.json`、`android-remote-list-parent-current-20261113.json`。

## 已实现

**iOS**：原生List及原任务进入／返回继续使用；补独立资料／账户定域的列表记录，保存设备筛选、分组、最近优先、置顶／最近／项目／工作区／无工作区折叠。阅读锚点按来源＋分组分别保存，任务身份使用host/thread，不保存本地化日期标题、搜索文字或当前选中任务来冒充阅读位置。切换来源、搜索／编写态和旧回调有隔离；普通任务返回保持当前List原生精确位置，冷启动才使用行锚点。

记录有版本、账户、数量／大小预算，原子写入成功才推进磁盘snapshot；损坏、错账户和未知版本保留原文件。读取／写入失败明确显示，页面本地仍可使用；当前UI写入失败与多scene并发冲突没有完整旅程，不声称服务偏好已确认。磁盘与约200ms合并写入属于独立前端设计，不是原数据库实现。

**Android**：按官方Android证据补优先、项目、时间三种实际列表投影及选择保存；优先顺序为等待审批／输入、未读、运行、最近。按更新时间／创建时间形成日期分区，保留源码中置顶与主列表可重复出现的行为。修复provider归档标记投影丢失；保存拒绝时筛选／折叠不先改显示；区分空目录与搜索无匹配。合成rank／时间／项目输入及同rank tie-break是独立适配，不是官方后端schema。

## 有界检查与已纠正的误判

- Foundation列表journal检查通过，覆盖A→B→A、跨主机同thread、重启、写入失败、坏文件／错scope／重复键与预算。
- iOS原有任务返回位置检查29.066秒通过；新增设备／分组／折叠／重启旅程，最终r3为58.758秒通过。r1只因原生Picker未暴露自定义AX identifier失败，改用293实际中文标签；没有为此改菜单样式。
- r2旅程虽然通过，但截图发现几何偏好使用了滚动前的List缓存cell坐标，锚点偏前。r3改为观察实际UICollectionView的bounds／contentOffset／adjustedContentInset及非交互行marker，在原容器中采样；没有替换delegate或增加手势。更严格的邻近行检查及前后截图已核对，不把r2误判重标正确。
- Android指定无线OnePlus四项通过：模型0.875秒、空列表6.807秒、整页41.708秒、重启12.487秒。APK安装与构建SHA一致，原普通预览的两个偏好摘要未变，独立中文浅色Remote预览留运行；未启模拟器。

## 明确没做

iOS原始viewport跨进程算法、行内像素恢复、锚点删除／折叠后的完整fallback、日期标题持久化、并发scene写冲突、完整分页和Live Activity实际卡片仍未实现。293的List<Never,Content>、selectedThread导航及账户级偏好wrapper已证明；通知授权回调3428a0不能解释为滚动恢复。

Android仍缺动态能力／真实未读与分页生产、部分自定义分区、连接设置实际接入、未取证的行手势及精确光学。所有界面数据仍为合成输入，可替换服务入口保留。

最终iOS签名构建通过，模拟器已更新；Air连接隧道失效，本批尚未补装真机，手机仍为前一批版本。不把安装当真机触感／手势／视觉证明。下一整项为Remote消息区，iOS继续收口、Android对齐当前组件／交互合同。本批最初仅保留本地；现按用户明确指令纳入已确定成果检查点推送，不发布Release。
