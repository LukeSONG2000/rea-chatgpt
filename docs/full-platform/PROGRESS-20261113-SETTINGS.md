# 第2项：指定设置接线（2026-11-13）

本批范围：主题、常规、已接入通知、Codex、帮助／关于、退出。iOS 优先，前端与平台能力接口；未扩展业务后端或 Android。

## 已实现

- 主题仍是一组：外观与强调色；外观支持跟随系统、浅色、深色并持久化。强调色既有 Remote／侧栏接线保留，本批补 Chat 用户气泡背景的实际消费，更新样式不替换相同正文和选区。Work 共用独立宿主组件；这不是原版 Work 同源证明。
- 常规的“应用语言”改为打开本应用系统设置，值来自当前 Bundle 的首选本地化语言；返回前台刷新，拒绝打开时显示错误。触觉反馈仍在常规，影响已接入的侧栏手势、状态胶囊、模型控制及文件导入反馈。
- 获取帮助补“关于”入口，位于隐私中心后。子页使用293原标签、OpenAI logo、平台及版本格式；版本取当前宿主 Bundle，不冒充官方1.2026.293。使用条款／隐私政策接已有资源预览，未注入资源服务时明确显示不可用，不联网。
- 原有通知权限读取／请求／管理、返回刷新、注册接口、取消、未读与点击定位继续保留。原有 Codex 连接前端开关、排序、全部启停、编写器键盘／上下文／后续行为及差异换行继续接对应消费端。
- 原有退出确认、重复提交抑制、匹配身份回执与取消返回保留。默认服务不可用不会伪装退出成功；匹配成功后的根路由属于显式合成认证旅程。
- 设置根关闭按钮仍归固定工具栏，条目滚动不带走关闭按钮。

- 报告应用问题：保留可返回的未连接入口。原 `BugReportPresenter+0x18` 注入工厂决定实际报告界面；其表单与提交未恢复，未自行编造“官方报告表单”。
- 通知的原类别偏好、原账号服务同步、真实推送发送／送达未实现；只接受独立 `rea_frontend_v1` 事件合同。
- Codex 的真实连接、Live Activity 未实现；原生设置载体精确视觉以及原上游能力配置仍有缺口。
- Chat 的 `disablesSharedTheme` 准入有原证据，当前普通预览采用允许共享主题的输入。原 Work 路由、其他特殊消息主题继承、完整账户主题同步未证明。
- About 原 identifier 等未知元数据不填；平台文字中文与当前原生排版属独立适配。
