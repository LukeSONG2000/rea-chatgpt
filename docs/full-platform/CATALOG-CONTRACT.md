# 本地会话生命周期：已实现的跨平台合同

这是独立恢复宿主的设计与验证结果，不是官方 schema 或服务端保证。iOS 证据见 [v50](../../analysis/full-platform-20261104/ios-rename-v50.json)，Android 见 [v49](../../analysis/full-platform-20261104/android-menu-rename-v49.json)。

| 边界 | 已实现的共同约束 | 平台差异与未验收 |
|---|---|---|
| 身份 | 新会话使用 canonical lowercase UUID；名称不是消息／草稿键 | A/B 历史键各端不同，需显式映射；不默认共享旧数据库 |
| 新建 | 持久化目录成功后才增加内存条目；默认标题避开当前同名编号 | 目录与当前选中项分开保存，跨文件原子性未证明 |
| 重命名 | UUID 不变；trim 后非空、最多 512 UTF-8 字节；取消不写入，失败保留原名 | 这是独立限制；iOS 中文为状态测试，Android 中文有原生输入与恢复证据；IME composing 未闭合 |
| 删除 | 先提交目录删除，再停止该作用域请求并清理草稿／消息；回退保留夹具 A | 客户端 cancelled 不是服务端取消回执；A/B 为保留夹具，不是最终产品限制 |
| 恢复 | 按存活目录过滤残留状态；冷启动与页面切换分别验收 | Android 缺目录时保护孤立数据；iOS 同等缺目录保护尚需核查，不能声称完全一致 |
| 原生交互 | 共享事件语义与验证要求 | iOS UIKit 滑动操作／UIAlertController；Android Compose 列表／DropdownMenu／AlertDialog，布局不是共享代码 |
| 验证 | 明确身份、取消、恢复、错误和其他会话不受影响 | Android 12+ 列表滚动已验证；iOS 长列表、两端无障碍、真实磁盘故障界面与物理设备未验收 |

开发上可共享合同与测试向量，保留各端菜单、输入法、选区、滚动和生命周期适配。现在没有足够证据推荐把主聊天 UI 统一为同一种组件框架。原始制品的宿主调用链、视觉参考及线上能力仍须独立证明。
